# Pre-Spike 因子研究 W4：修正 base rate + 新时间外推

> 这是一轮 WARNING/pre-event 研究，不是做空入场回测。测试段 2026-08 为前述 W1/W2 未使用的新 holdout。

## 1. 实验协议

- 归档候选 symbol: 509；实际有足够数据: 509
- train: `2026-02-01T00:00:00+00:00` ≤ t < `2026-07-31T23:00:00+00:00`
- embargo: `2026-07-31T23:00:00+00:00` → `2026-08-01T00:00:00+00:00`
- test: `2026-08-01T00:00:00+00:00` ≤ t < `2026-08-22T00:00:00+00:00`
- 有效 1m bars: train=127,570,177 / test=12,095,465
- spike 标签：未来 N 根 1m 内出现 `high >= 前一根 close × 1.15`；**不含当前 bar**。
- base rate：在完全相同的 future 标签、完整 horizon 和有效因子观测集合上计算。
- genuine pre-event 约束：当前及过去 20 分钟不得已经出现 15% spike。
- alert episode cooldown: 5 根 1m；避免连续状态重复报样本。
- 规则只从预先声明的 32 个数值阈值组合中选择；test 不 qcut、不重拟合阈值。
- train 最低触发数: 100；主选择 horizon=5m。
- 运行耗时: 66.9s

## 5. 结论

- train 5m lift = **1618.86**；test 5m lift = **750.14**。
- test 触发 104 次，命中率 0.962%，背景 0.001%。
- test 事件级 recall = 3.125%，平均提前 3.00m。
- 组合相对最强单因子 test precision 增量 = **4.54×**。
- 虽然 enrichment 明显，但 precision/recall 都偏低：当前只能作为极窄的候选池 gate，不能称为完整 WARNING，更不能触发挂单。

## 6. 解释边界与下一步

1. 主结论优先看按日 block-bootstrap；Wilson CI 仅保留用于直观展示单条 alert 的二项区间。
2. 当前 target 是 1m 内 15% 极端上冲，和 1s spike 触发并非完全同一个标签；本轮回答的是 WARNING/universe 预热价值。
3. 本轮不计算 MFE/MAE ‘expectancy’，因为 pre-event 信号不是做空入场，且极值没有触达顺序。
4. 若规则样本外有效，下一轮应加入 OI/多空比慢因子和 BTC-relative 因子，检验增量 lift，而不是直接加到 scoring。
