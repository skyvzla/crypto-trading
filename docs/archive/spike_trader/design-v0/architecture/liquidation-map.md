# 清算地图（暂空）

清算地图未来只可能作为清算尖峰策略内部的辅助参考；当前不接入、不定义 Interface，也不属于公共行情模块。

在拿到真实接口返回样例并确认具体用途前，本文件不定义：

- 提供商、请求方式、认证、更新周期或缓存；
- 任意响应字段、数据模型、质量规则或归档方式；
- 如何影响挂单价格、失效价、评分、止盈或止损；
- 任何 API 失败、缺失或延迟时的交易动作。

当前策略完全使用本地 1s 行情和 ATR 估算。没有地图数据时照常产生候选、开仓和管理已有交易轮次；地图不会成为候选、订单、风险或持仓管理的门禁。

后续只有在提供真实接口结果、明确“参考辅助”的具体决策点后，才在策略内部补充独立设计。届时仍不把它抽取为公共行情模块，除非出现第二个真实消费者。
