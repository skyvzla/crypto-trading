# 交易轮次与持仓生命周期

## 已确认规则

- 全局同一时间只允许一个交易轮次，交易中不接受其他信号。
- 一轮交易使用固定总名义金额 `N USDT`，分为 30% / 40% / 30% 三档。
- 三档可以部分成交；未成交部分不转移为额外加仓。
- 第一笔实际成交后立即进入保护，并从第一笔成交开始计时。
- 触发失效条件时撤销未成交入场单；已有仓位继续退出。
- 持仓达到 900 秒且净收益不为正时退出。
- 盈利仓位使用止盈策略管理，不因 900 秒直接退出。
- 盈利且超过 900 秒出现新有效信号时，先平旧轮次，确认旧仓位结束后再开新轮次。
- subcategory 关闭只影响新开仓；已有仓位继续保护和退出。

## 待确认

- 交易轮次、订单、成交和仓位的具体状态名称；
- 保护单、止盈单和退出单的具体订单类型；
- 部分成交均价、手续费、滑点和异常成交的计算方式；
- 重启、对账、迟到回报和未知订单的具体实现。

本文件不指定数据库、消息格式、订单字段或代码状态机。
