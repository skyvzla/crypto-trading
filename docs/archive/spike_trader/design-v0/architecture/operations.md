# 运行范围

## 已确认模式

| 模式 | 用途 |
|---|---|
| `replay` | 离线历史回放和回测 |
| `testnet` | 测试网实时执行 |
| `live` | 正式账户实时执行 |

不提供实时纸盘模式。清算地图当前不属于任何模式的必要输入。

## 已确认运行约束

- 测试网和正式账户必须隔离。
- 实盘启用前需要测试网验证和人工确认。
- 数据、订单或仓位状态无法确认时，不得继续新开仓；已有仓位优先保护和退出。
- 运行过程需要能够恢复未终态交易轮次，但恢复实现方式待确认。

## 待确认

- 启动、停止、暂停、恢复和紧急平仓流程；
- 监控、告警、凭据管理和部署方式；
- 交易所连接、重试、对账和故障恢复实现。
