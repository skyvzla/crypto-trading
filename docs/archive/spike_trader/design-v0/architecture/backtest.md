# 回测与验证

## 已确认范围

- 历史回测只验证本地 1s 行情、ATR 估算、三档入场和退出规则。
- 清算地图没有历史数据，当前不进入回测。
- 回测使用 `scripts/backtest_dynamic_spike.py` 及其配套脚本作为行为基线，不把脚本结果直接当作生产结果。
- replay 的模拟成交只存在于离线回放，不提供实时纸盘模式。

## 阶段 0 必须先验证

- 当前分钟的未来高点不能进入信号计算；
- 未完成的 5m Bar 不能进入 ATR；
- 失效条件发生后，后续未成交档位不能继续成交；
- 部分成交后保护和持仓计时从第一笔成交开始；
- 同一时间同时触发止损和止盈时采用已确认的保守顺序；
- 线性合约空头 PnL、手续费和滑点口径需要确认。

## 待确认

- 回测成交模型、部分成交模型和输出格式；
- 回放所需的数据存储和时间接口；
- 回测通过标准和需要比较的指标。

不在本文件猜测成交 Adapter、数据表、报告字段或敏感性模型。
