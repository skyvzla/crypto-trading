# 交易池发现与监听租约

## 已确认流程

```text
subcategory 准入范围
  -> 低频发现扫描
  -> 监听租约
  -> 监听池
  -> 1s 策略监听
```

- 发现扫描周期不固定为 3 分钟，具体周期待确认。
- 发现扫描不是短期交易信号；交易对进入监听池后，才计算 1s 尖峰条件。
- 交易池范围内未获得监听租约的交易对不建立 1s 策略监听。
- 发现后需要持续观察一段时间，横盘本身不立即移除。
- 跌幅吞没大部分原上涨动能，或达到观察期限后，可以移出监听池；精确定义待确认。
- subcategory 关闭时撤销未成交入场单；已有仓位继续保护和退出。
- 有未终态交易轮次时，可以为保护和退出临时保留监听；该监听不能产生新候选。

## 待确认

- 入池条件和使用哪些低频数据；
- 起涨锚点、最高价、回吐比例和连续确认规则；
- 观察期限、扫描周期和重新入池规则；
- 租约需要保存的字段和审计方式。

本文件不定义回吐公式、百分比、小时数、Top N 或任何代码结构。
