# 系统范围与职责

## 已确认范围

- 新系统服务清算尖峰上涨后做空策略。
- 策略只接收完成的 1s Bar，不接收 tick 作为策略输入。
- 运行模式为 `replay`、`testnet`、`live`；不提供实时纸盘模式。
- 新系统与旧 `src/crypto_trader/` 的账户、风险、执行和持仓语义分开。
- 清算地图当前暂空，不进入系统接口或开仓门禁。

## 已确认职责

系统需要具备以下业务职责：

1. 从监听池交易对接收完成的 1s Bar。
2. 根据当前策略规则生成候选和三档本地价格计划。
3. 保证同一时间只有一个交易轮次。
4. 管理部分成交、失效、900 秒风险超时、盈利管理和信号切换。
5. 将交易所成交作为仓位事实，并支持重启后的保护和恢复。
6. 提供浏览器交易池 subcategory 开关。

## 尚未确认

以下内容不在当前架构中指定：

- Python 包结构、进程拆分和模块类名；
- 行情、交易所、账本、数据库、缓存和 Web 技术；
- 订单事件、状态字段、持久化表和接口签名；
- 部署、告警、重试和恢复的具体实现。

这些事项需要在实现阶段单独确认，不能从本文件推导出代码。
