# 行情数据约束

## 已确认

- 策略以交易所时间窗口结束后的完成 1s Bar 为输入。
- tick 或原始成交只能在行情聚合内部使用，不能进入策略接口。
- 只有监听池交易对需要建立 1s 策略监听；不监听全市场。
- 发现扫描使用低频行情确定需要持续观察的交易对。
- 1m/5m 数据只作为本地估算辅助，不能使用信号时刻之后或尚未完成的 Bar。
- 新监听交易对在数据不足时不能产生有效候选。

## 待确认

- 行情供应商、订阅方式、聚合方式和断线处理；
- 1s Bar 的具体字段、时间戳和质量标记；
- 历史行情的存储和回放格式；
- 缺口、乱序、延迟和预热的具体阈值。

清算地图不属于当前行情数据接口；它的接口和字段尚未确认。
