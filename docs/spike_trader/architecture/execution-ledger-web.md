# 执行、账本与 Web 控制

## 已确认规则

- 策略只能产生交易意图，不能绕过交易轮次直接叠加开仓。
- 每轮总名义金额不超过 `N USDT`，三档按 30% / 40% / 30% 分配。
- 订单成交和仓位事实以交易所实际成交为准，不能把提交成功当作成交。
- 测试网和实盘是唯一的实时执行环境；模拟成交只属于离线 replay。
- 浏览器只负责 subcategory 交易池准入控制，以及关闭准入时撤销未成交入场单。
- 浏览器不热更新策略参数。

## 待确认

- 交易所订单接口、订单类型、合约过滤器和账户连接方式；
- 账本存储、订单幂等键、对账和重启恢复方式；
- Web 技术、权限、页面和审计字段；
- 暂停、紧急平仓及其他操作性控制是否纳入首版。

当前不定义数据库表、代码 Adapter、接口签名或 Web 页面字段。
