# 分阶段实施计划

阶段只描述工作目标，不预设技术选型或未确认参数。

## 顺序

```text
阶段 0 基线确认
  -> 阶段 1 策略核心
  -> 阶段 2 执行与恢复
  -> 阶段 4 交易池 Web 控制
  -> 阶段 5 测试网
  -> 阶段 6 实盘灰度
```

阶段 3 清算地图当前暂空，不是任何阶段的依赖，也不阻塞测试网或实盘。

## 阶段目标

| 阶段 | 目标 |
|---|---|
| 0 | 核对脚本基线，修正并测试数据和生命周期问题 |
| 1 | 实现可确定回放的 1s 策略和交易轮次核心 |
| 2 | 确认测试网执行、账本和恢复方案 |
| 3 | 清算地图预留，等待真实接口和用途确认 |
| 4 | 实现 subcategory 交易池浏览器控制 |
| 5 | 测试网验证真实执行和交易轮次约束 |
| 6 | 正式账户小范围灰度 |

每阶段完成前，未确认的技术细节不能自行落地。
