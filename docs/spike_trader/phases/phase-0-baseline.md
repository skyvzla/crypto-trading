# 阶段 0：脚本基线

## 目标

以 `scripts/backtest_dynamic_spike.py` 及配套脚本为依据，建立可复核的基线并确认哪些规则进入重构。

## 工作

- 核对触发、三档价格、失效价、订单等待窗口和当前 PnL 计算；
- 修正未来数据、未完成 Bar、部分成交和持仓计时问题；
- 用固定案例覆盖无成交、部分成交、失效、900 秒和信号切换；
- 将通过确认的规则与参数记录下来。

## 不做

- 不接入清算地图；
- 不接真实或测试网订单；
- 不加入其他策略或新的账户级风控。

## 退出条件

脚本差异可解释，修正后的规则获得确认，且同一输入可以重复得到一致结果。
